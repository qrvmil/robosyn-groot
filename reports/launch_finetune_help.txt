usage: launch_finetune.py [-h] [OPTIONS]

Configuration for fine-tuning a Vision-Language-Action (VLA) model. This 
dataclass defines all parameters needed to launch a fine-tuning job on a 
pretrained base model using a custom dataset and embodiment-specific modality 
configuration. It controls model tuning options, data augmentation, and 
training hyperparameters.

│                                                                            │

│       - "contrast": float                                                  │
